Proficiency indicators — comparison mockup

Research-backed alternatives to the plain 5-dot rating, extending it rather than replacing it. Nothing here is wired to real data yet — this is purely "how would it look."

Target marker — caret sits above the cell you're aiming for
▲+1 Trend — direction + change since last check-in
Confidence — how much evidence backs this number (more bars = more evidence)
95d Recency — only shown when stale; silence means "recently active"

1. Build-up: one node, one layer at a time

Node: "Celery / async tasks" — current proficiency 2, target 3, confirmed via 4 commits over the last 2 weeks but trending down from a peak of 3 last month.

Today (baseline) ← current level only. No target, no trend, no confidence, no recency.
+ target marker ← now you can see the gap: 2 of 5, aiming for 3.
+ trend ▼−1 ← was at 3 last month, dropped to 2 — regressing, not just "below target."
+ confidence ▼−1 ← 2 bars: a handful of commits, not a huge sample — moderate confidence.
+ recency (not stale here) ▼−1 ← no clock badge appears — this was touched 3 days ago, so recency stays silent.

3. What each piece is actually answering

ElementQuestion it answersPattern used (see research)
Cells + caretWhere am I vs. where should I be?Mini bullet graph (Few) — cells keep the dots' small-size robustness, caret adds the target Few's tick mark gives a full bar
▲/▼/▬ + deltaIs this getting better or worse?Lichess-style arrow+delta, not a full sparkline — more legible than a line at this size
Signal barsHow much should I trust this number?Signal-strength meter, monochrome so it never fights the trend's color
Clock badgeIs this stale?Shown only when stale (silence = fresh) — avoids a 4th always-on element crowding the row
